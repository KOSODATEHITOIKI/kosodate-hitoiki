# M PLUS Rounded 1c

Google Fonts公式リポジトリから取得した未改変のTTFを同梱する。
400（Regular）、500（Medium）、700（Bold）、800（ExtraBold）を使用。

- 配布元: https://github.com/google/fonts/tree/main/ofl/mplusrounded1c
- ライセンス原本: https://github.com/google/fonts/blob/main/ofl/roundedmplus1c/OFL.txt
- Copyright 2016 The Rounded M+ Project Authors.
- SIL Open Font License 1.1: 同梱の `OFL.txt` を参照。

フォントとライセンスは `pubspec.yaml` に登録し、実行時のダウンロードは行わない。
