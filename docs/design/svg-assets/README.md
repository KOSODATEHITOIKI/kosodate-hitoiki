# ひと息 B案 水彩風SVG素材集

オリジナルの編集可能なベクター素材。背景は透明。承認済みの太陽を基準に、水彩風の色むら・筆跡をベクターで描いています。操作アイコンは小さくても読める丸い線を維持しています。元の画像との完全一致ではなく、同じ雰囲気に寄せた描き直しです。

## 命名
半角英小文字の kebab-case。`icon-用途-意味.svg`、`illustration-状態.svg`、`decoration-モチーフ.svg`、`avatar-default-モチーフ.svg`、`reaction-意味.svg`。
色・連番・仮のサービス名をファイル名に含めず、用途が変わらなければ同じ名前を使います。

## 利用
アイコンは24×24、線幅2、丸い端。装飾・イラスト等は240×240。SVGをFigmaへドラッグして編集できます。
文字・外部画像・フォント・スクリプト・フィルターへの依存はありません。各ファイルのtitleは日本語の用途です。
アプリ側でボタンに日本語ラベルを付け、装飾画像は読み上げ対象から外してください。色はSVG内のfill/strokeで変更可能です。
Google・Appleのブランドロゴ、ユーザーがアップロードする画像は含みません。リアクション文言と既定アバターの採用は提案です。

## Flutter用の変換版
patternを直接描画する図形とclipPathに展開。PNGの埋め込みなし。元の色・質感・名前を維持。ブラウザー相当の描画で比較済み。flutter_svg 2.3.0のFlutterテストエンジンで全89点の描画を確認済み。2.0.10+1と実機では未検証です。詳細はFLUTTER-VALIDATION.md。図形数が増えるためイラストは事前読み込みなど描画負荷の確認が必要です。

### 案内画面の太陽（2026-10-14）

`assets/decorations/decoration-sun-simple.svg` はS-01「自分のペースで大丈夫」用の顔なし太陽。笑顔の太陽から顔・頬のグループを除いたSVGで、水彩の円と光線、中央配置を保持する。ヘッダーには引き続き `decoration-sun-smiling.svg` を使う。
