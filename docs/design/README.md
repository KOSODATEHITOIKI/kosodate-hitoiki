# デザインモックアップ(2026-09-29確定)

高精細モックアップ一式。アプリ名は「ひと息」で確定。実装時はこのフォルダの画像を一次参照とする。

全24枚の文字・画像・カード幅・余白の概算と、画面幅に応じた配置方針は[デザイン寸法の観察記録](MEASUREMENTS.md)を参照。PNG上の寸法はFlutterの固定値ではなく、比率を比較するための記録。

> 📝 このモックアップは暫定の参照資料。今後Figmaで正式なデザインファイルを作成する予定で、その際は本フォルダの画像を削除し、Figmaへのリンクに置き換える。

## デザインシステム

- **背景**: 生成り色(暖色系クリーム)に、オレンジ〜黄色のやわらかい雲のイラスト
- **プライマリボタン**: コーラルオレンジの角丸ボタン
- **セカンダリボタン**: 黄色のピル型ボタン
- **見出し**: 濃い茶色、丸みのある太字書体
- **マスコット**: 笑顔の太陽キャラクターが各画面に登場
- **ユーザーアイコン**: 選択式のイラスト(芽・花・チューリップ・鳥など、S-09参照)
- **リアクション**: ハートアイコン「わかる」(ピンク系)、拍手アイコン「おつかれさま」等(黄系)、いずれもピル型で件数表示

## 現行docsとの差分メモ

以下はこのモックアップで初めて具体化された、`全体設計書.md`にまだ反映されていない要素。実装時にNotion側の決定事項と照合し、未決定のものは確定事項として扱わない。

- 書く画面: 初回投稿時に「はじめて投稿する前に」モーダル、送信不可時は「投稿の確認」画面(名前の言い換え例テーブル付き)で書き直しを促すフロー
- 投稿詳細: 未ログイン時にコメント欄が「続きを読むにはログイン」モーダルで遮られ、ログイン完了後に元の投稿へ戻る
- マイページ: 投稿の「…」メニューに「反応モードを変更」「コメント受付を終了」が個別項目として存在
- 設定配下に「通知設定」「ブロック管理」の専用画面(ミュート管理は未確認)
- プロフィール編集のアイコン選択肢: 芽・花・チューリップ・鳥(4種、初期版)
