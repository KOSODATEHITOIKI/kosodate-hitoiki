受付時間・対象地域など変更されやすい詳細はアプリへ転記せず、公式ページで確認してもらう。189は案内番号を表示するだけで、自動発信や電話アプリの起動は行わない。外部サイトに投稿本文や利用者情報を付与しない。

公開前・各リリース前にリンクを開いて、提供元・転送先・受付対象に変更がないか確認する。公開後も定期的に確認し、URL変更時は `SupportResourcesPage` とURL検証テスト、本書を一緒に更新する。CIから公的窓口へのアクセスは行わず、外部URLの起動成功/失敗は差し替えたランチャーで検証する。

ブラウザ起動に失敗した場合は案内とコピー可能なURLを表示する。画面自体はログイン不要で、ホーム・設定・投稿確認の相談先案内から開ける。
